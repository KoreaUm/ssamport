쌤포트 v2.0.146은 AI 채팅에 파일 첨부 기능을 더한 업데이트입니다.

- AI 채팅에서 엑셀(.xlsx/.xls), CSV, PDF 파일을 첨부해 그 내용을 바탕으로 질문할 수 있게 되었습니다. 입력칸 옆 📎 버튼으로 첨부하면 됩니다.
- 첨부한 내용에 학생 이름·연락처 등이 있어도 클라우드 AI로 보낼 때는 자동으로 가명 처리되도록 안전장치를 두었습니다.
- 파일을 첨부한 뒤 입력칸을 눌러도 글자가 써지지 않던 문제를 고쳤습니다.

검증: 회귀 테스트 28개 통과, 실제 학생 명단 파일과 설명서 PDF를 첨부해 질문·답변까지 직접 확인.
