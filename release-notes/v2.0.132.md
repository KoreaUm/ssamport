쌤포트 v2.0.132는 데이터 저장과 복원, Google 동기화, 회원 권한을 보완한 업데이트입니다.

- 학생 CSV는 기존 기록을 유지하며 명단을 갱신합니다. 학생·보호자 연락처 입력을 추가했습니다.
- 백업 복원 후 DB 연결과 계정별 DB 이전 시 최신 기록 보존을 수정했습니다.
- 수행평가 점수의 빈칸 삭제·범위 검증·일괄 저장과 반별 입력 인원 통계를 수정했습니다.
- Google 삭제 실패를 보관해 재시도하며, 미전송 변경과 최신 수정 시간을 구분합니다.
- 기존 Google OAuth 설정을 유지하고 캘린더 날짜 계산을 수정했습니다.
- 로컬 저장·외부 동기화 상태, 실패 재시도, 원격 변경 알림을 추가했습니다.
- 시간표·메모 저장과 빠른 화면 이동을 보완하고, 공문 작성 중 이동 시 확인합니다.
- 회원 생성 시 권한 임의 지정과 비활성 관리자 접근을 차단했습니다.

검증: 회귀 테스트 23개, Electron 화면 테스트, Firebase 서버 권한 테스트 11개 통과.
