쌤포트 v2.0.136 업데이트 안내입니다.

- 로컬 AI(Qwen3)로 할일을 추출할 때, AI의 생각 과정 글자가 결과에 섞여 나오던 문제를 완전히 고쳤습니다.
- 상단바 'AI 설정'에서도 설정 화면과 동일하게 Groq·OpenRouter 무료 AI를 선택할 수 있도록 했습니다.
- 대시보드와 위젯에서 Local AI Basic/Pro를 선택했을 때 할일 추출이 안 되던 문제를 고쳤습니다.
- 학교폭력 공문의 위원 명단·사건번호를 계정별로 저장해, 같은 컴퓨터를 쓰는 다른 선생님과 내용이 섞이지 않도록 했습니다.
- Groq·OpenRouter 외부 AI 연결 시 자주 발생하던 오류(키 오류, 더 이상 무료가 아닌 모델 오류)를 고치고, 최신 무료 모델로 교체했습니다. OpenRouter는 원하는 무료 모델 이름을 직접 입력해 쓸 수 있게 했습니다.
- 외부 AI를 처음 연결할 때 보이는 동의 안내를 더 쉬운 문장으로 바꾸고, 상단바에서 바로 연결할 때도 설정 화면과 똑같이 동의 안내가 나오도록 했습니다.
